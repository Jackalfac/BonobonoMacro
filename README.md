# BONOBONO MACRO — 설치 및 상세 사용법

Windows 64비트용 게임 보조 매크로입니다. 좌표 반복, 자동사냥 횟수 보충, 게임 안 주식 가격·보유량 확인을 지원합니다. 설치본은 Python을 별도로 설치하지 않아도 실행할 수 있습니다. 프로그램 사용에는 유효한 사용자 인증이 필요합니다. 누구나 다운로드할 수 있다는 뜻이 인증 없이 실행된다는 뜻은 아닙니다.

## 사용법·설치 문의

[텔레그램으로 문의하기](https://t.me/BonobonoMacroSupport?direct)

설치, 인증, 화면 교정, 사용법 관련 문의를 채널 전용 다이렉트 메시지로 보내주세요. 오류 문의에는 설치 버전·발생시각·오류 문구를 함께 적어주세요.

## 다운로드 및 설치

1. [최신 Release](https://github.com/Jackalfac/BonobonoMacro/releases/latest)를 엽니다.
2. Assets에서 **Bonobono_Setup_latest.exe**를 다운로드합니다. Source code ZIP은 설치파일이 아닙니다.
3. 실행 중인 기존 매크로가 있으면 F12로 멈추고 프로그램을 정상 종료합니다.
4. 설치 EXE를 실행하고 설치 안내를 따릅니다. 기존 개인 설정을 직접 삭제하지 마세요.
5. 설치된 BONOBONO MACRO를 실행하고 본인에게 발급된 인증 정보로 로그인합니다. 인증 정보가 없거나 PC 등록 제한이 나오면 배포자에게 문의하세요.

선택 확인: 함께 제공하는 `.sha256` 파일의 값과 PowerShell `Get-FileHash .\Bonobono_Setup_latest.exe -Algorithm SHA256` 결과를 비교할 수 있습니다. 패키지 내부 무결성 검증과 Windows 게시자 인증은 별개의 사항입니다.

## 먼저 알아둘 화면 조건

- 게임 **내부 화면 1280×720**, 게임 설정의 **UI 크기 기본값(슬라이더 가운데)**가 기준입니다.
- 실행할 게임 창을 직접 선택합니다. 여러 게임 창이 있으면 제목과 대상을 확인하세요.
- 상단 **1280×720 맞춤**으로 게임 창 크기를 맞출 수 있습니다. 이것은 게임 UI 크기 슬라이더나 교정값까지 자동으로 맞춘다는 뜻은 아닙니다.
- 동일 해상도라도 PC의 배율과 실제 화면 배치가 다르면 좌표·인식 자료가 맞지 않을 수 있습니다.
- 공개 설치파일에는 사용자의 인증 캐시, 개인 프리셋, 주식 DB와 개인 화면 교정본을 포함하지 않습니다. 특히 새 PC에서 사냥·주식 기능은 교정 준비 없이 바로 시작되지 않을 수 있습니다.

## 기본 화면과 단축키

왼쪽 작업 목록에서 편집할 작업을 고릅니다. 작업을 클릭해서 보는 것과 그 작업을 실행에 포함하는 것은 별개입니다. 실제 실행할 작업에만 실행 포함을 설정하세요.

| 항목 | 역할 |
|---|---|
| F8 | 좌표 추가 |
| F9 | 선택 좌표 변경 |
| F11 / 전체 시작 | 실행에 포함한 작업 시작 |
| F12 / 전체 중지 | 모든 매크로 작업 중지 |
| 전체 저장 | 현재 전체 설정을 프리셋으로 보관 |
| 상세 로그 | 현재 진행과 오류 내용 확인 |
| 도움 · 도구 → 주식 체크 목록 | 주식 대상·가격·보유량과 관련 설정 열기 |

실행 중인 작업의 설정은 편집이 제한됩니다. 수정하려면 F12로 멈춘 뒤 변경하세요. F12는 매크로 입력을 멈추는 기능이며 게임 자체의 자동사냥 종료 버튼과는 다릅니다.

## 자동사냥 횟수 보충 설정

이 기능은 게임 자동사냥을 보조하여 횟수창의 `+` 버튼을 누르는 기능입니다. 이동·전투 전체를 새로 수행하는 범용 사냥 AI는 아닙니다.

1. 게임에서 원하는 사냥을 준비하고 자동사냥이 활성화된 화면을 둡니다.
2. 왼쪽 자동사냥 작업을 선택합니다. 자동사냥은 1번 작업에서 설정합니다.
3. 현재 게임에 맞게 **필드 / 함선**을 선택하고 **1번 사용**을 체크합니다.
4. **점검 간격 · 초**를 입력합니다. 예를 들어 `300`은 5분 간격 설정입니다. 전체 작업 소요시간과 차례 대기의 영향을 받으므로 매시 정각 예약과는 다릅니다.
5. **전체 반복**에 처음에는 `1`을 넣어 한 차례를 확인합니다. 반복 사용하려면 `0=계속`을 선택할 수 있습니다.
6. **보충 클릭**에 원하는 횟수를 입력합니다. 범위는 1~140이며 실제 검증 예시는 `40`입니다.
7. **자동사냥 화면 설정 · 누락 교정 복원 / 새로 만들기**를 엽니다. 맞는 검증 교정본이 있으면 복원하고, 없으면 안내에 따라 실제 화면으로 새 교정을 완료합니다.
8. 교정 완료 뒤 횟수창을 닫고 설정을 저장합니다. F11로 시작합니다.
9. 로그에서 보충 실행과 사냥 화면 복귀를 확인합니다.

**40회 설정은 최대 횟수까지 정확히 채운다는 뜻이 아니라 +버튼을 40회 누른다는 뜻입니다.** 일반 보충은 남은 횟수 OCR로 부족분을 계산하지 않습니다. 창·버튼·사냥 상태를 확인하고 정해진 횟수만 클릭한 뒤 닫습니다.

가림 팝업 자동 처리를 쓰려면 **가림 팝업의 확인 버튼 자동 처리**를 선택합니다. 등록된 창·버튼·위치가 재확인되는 팝업만 처리하며 모든 종류의 팝업을 자동 처리하지는 않습니다.

## 게임 안 주식 가격·보유량 확인

게임의 주식 화면을 조회하는 기능입니다. 실제 증권 서비스와 무관하며 게임 안 주식도 자동으로 매수·매도하지 않습니다.

1. **도움 · 도구 → 주식 체크 목록**을 엽니다.
2. 확인할 종목의 체크칸을 선택합니다. 가격이나 이름을 누르는 것과 체크 변경은 별개입니다.
3. 주식 작업이 연결된 그룹의 실행 포함 상태를 확인합니다.
4. 실행 방식은 반드시 **순서대로**를 선택합니다. 주식 작업은 함께 반복 모드에서 실행할 수 없습니다.
5. 점검 간격과 한 차례에 확인할 최대 종목 수를 원하는 값으로 설정합니다.
6. 현재 화면과 맞는 주식 이동 경로·상세 인식·종목 위치 교정자료가 준비됐는지 확인합니다. 기본 종목 목록이 보이는 것만으로 실제 위치 등록이 끝난 것은 아닙니다.
7. 새 PC에 교정자료가 없거나 '위치 재등록 필요'가 나오면 해당 PC 화면에 맞는 자료를 준비해야 합니다. 해상도 숫자만 바꾸거나 다른 PC의 자료를 무조건 덮어쓰지 마세요. 준비되지 않으면 배포자에게 현지 교정 지원을 요청하세요.
8. 설정 닫기 또는 작업 전환으로 초안을 적용하고 **전체 저장**으로 보관합니다.
9. F11로 실행한 뒤 하단 실시간 주식 기록과 종목 목록에서 결과를 확인합니다.

수집 과정에서는 지역·레벨·자원으로 종목을 식별하고 서로 다른 두 화면의 가격·보유량을 대조합니다. 유저/최대주주 닉네임은 바뀔 수 있어 종목 식별 기준에서 제외합니다.

한 차례 점검 시간은 제한되어 있습니다. 약 30초 예산 안에 끝내지 못한 종목은 사냥 화면으로 안전 복귀한 뒤 다음 차례에 이어 확인합니다. 선택한 모든 종목이 매 차례 한꺼번에 끝나지 않을 수 있습니다.

## 사냥 보충과 주식을 함께 반복하기

1. 자동사냥과 주식 각각의 교정·단독 설정을 먼저 확인합니다.
2. 두 작업을 실행에 포함하고 **순서대로**를 선택합니다.
3. 예시로 사냥 점검 300초, 보충 40회, 주식은 원하는 종목을 선택할 수 있습니다. 이는 사무실 실측 예시이며 모든 사용자의 필수값은 아닙니다.
4. 전체 저장 후 F11로 시작합니다.
5. 사냥 보충 → 주식 확인 → 사냥 화면 복귀 → 다음 차례 대기 흐름을 로그에서 확인합니다.
6. 처음에는 한 차례를 직접 지켜보고, 이상이 있으면 F12로 중지합니다.

## 가격 알림·통계 읽는 법

주식 목록에서 원하는 종목의 가격알림·통계 화면을 엽니다.

- **목표가 이하 / 이상:** 원하는 가격을 입력해 조건을 설정합니다.
- **급등 / 급락 비율:** 직전 확인 가격 대비 변동 비율을 개인 기준으로 입력합니다.
- **빈칸:** 해당 알림만 끄며 가격 수집은 계속합니다. 임의의 알림값이 자동으로 켜지지 않습니다.
- 최초 관측은 비교 기준을 만들며, 같은 가격을 반복 확인할 때마다 같은 변동 알림을 반복하지 않습니다.
- 목표가 알림은 조건에 다시 진입하면 재알림할 수 있습니다. 개별 고급 조건을 기존에 사용했다면 설정을 별도로 확인하세요.

가격이 같으면 가격변동 이력을 중복 추가하지 않고 마지막 확인시각·보유량·관측 유지구간을 갱신합니다. 가격이 바뀌면 새 표본을 저장합니다. 확인 횟수와 가격변동 표본 수는 다릅니다.

통계 기본 기간은 최근 7일입니다. 전체/24시간/7일과 최저·최고·시간가중평균 등을 확인할 수 있습니다. 시간가중평균은 관측 사이 가격이 유지됐다고 가정하되 긴 미관측 공백을 제외합니다. 관측하지 않은 순간의 실제 변동은 알 수 없습니다. 표본 20개 기준과 마지막 정상 확인 후 24시간 경과 안내는 정보 품질을 판단하는 안내이며 수집 자체를 막는 조건은 아닙니다.

## 보유·거래 기록

보유 기록 화면에서 매입·매도 기록, 평균매입가와 보유량, 마지막 매도시각 등을 관리할 수 있습니다. 입력한 기록과 화면에서 관측한 보유량을 구분하세요. 실제 체결·원가를 자동 추정하거나 게임에서 주문하는 기능은 없습니다. 매도시각 기준 24시간 재구매 제한 안내를 참고할 수 있습니다.

## 일반 좌표 반복 작업

자동사냥 외의 좌표 작업은 2~4번 작업에서 설정합니다. 대상 창을 확인하고 F8로 포인트를 추가하거나 선택한 포인트를 F9로 변경합니다. 클릭 횟수·간격·동작 후 대기·전체 반복을 설정하고 필요한 작업만 실행에 포함하세요. 처음에는 유한한 횟수로 시험합니다. 여러 그룹을 쓸 때는 클릭 겹침 방지를 사용해 입력을 차례로 처리할 수 있습니다.

## 저장·종료·업데이트

작업 전환과 설정 닫기는 현재 입력 초안의 적용이며, 다음 실행을 위해 보관하려면 **전체 저장**을 사용합니다. 그룹별 불러오기는 해당 그룹만, 저장한 4그룹 전체 복원은 전체 구성을 바꿀 수 있으므로 범위를 확인하세요.

종료 전 F12 → 전체 저장 → 프로그램 정상 종료 순서를 권장합니다. 업데이트할 때 개인 인증·프리셋·주식 DB·교정파일을 임의 삭제하지 마세요. 새 PC에는 다른 PC의 인증 캐시를 복사하지 않습니다.

## 문제 발생 시

| 증상 | 확인할 내용 |
|---|---|
| 시작 전 교정 누락 안내 | 자동사냥 화면 설정에서 맞는 교정본 복원 또는 새 교정 완료 |
| 주식 시작 거부 | 순서대로 모드, 선택 종목, 실행 포함, 현지 경로와 종목 위치 교정 확인 |
| 화면 크기 불일치 | 게임 내부 1280×720과 UI 기본 크기를 확인하고 현지 교정 점검 |
| 판독 실패·확인 불가 | 게임의 창·상세 로딩을 확인. 옛 가격이 표시돼도 새 수집 성공으로 보지 않기 |
| 팝업 뒤 중지 | F12로 정지 상태 확인 후 화면과 로그 점검. 등록되지 않은 팝업은 직접 확인 |
| menu_appearance_changed 등 화면 대조 오류 | 실제 화면이 기존 교정과 맞는지 확인. 무작정 반복 시작하기보다 교정 자료 점검 |
| 인증 실패·중복 실행·PC 제한 | 다른 실행본을 종료하고 인증/PC 등록 상태를 배포자에게 확인 |

오류 문의에는 발생시각, 설치 버전, 오류 문구와 인증정보를 가린 화면을 첨부하세요. 실패 시 프로그램이 남긴 PNG/JSON 진단자료는 원인 분석에 도움이 됩니다. 개인 인증값은 공개 게시하지 마세요.
